Vair

Companion app. View and share only — authoring happens in VR.

Scope for v1 (plan.md §10):

  • Account and credential entry — all keys live on the server
  • Scene library with thumbnails
  • Share links and a static viewer
  • Capability toggles, delivered to the headset as a manifest

Not a 2D scene editor. A web editor is a second product that would compete with the pitch. Ships with M6 — see plan.md §12.
